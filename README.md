# ExploreCanadianProvinces

An interactive educational website built with HTML, CSS, JavaScript, and JSON that lets users explore Canadian provinces and territories through dynamic content, time zones, fun facts, images, and videos.

## Features
- Dropdown-based navigation for all Canadian provinces and territories
- Dynamically updates content using JSON data
- Displays:
  - General information
  - Capital city details
  - Political information
  - Fun facts with images
- Province-specific local time using time zone offsets
- Embedded YouTube videos for each province/territory
- Responsive layout with interactive styling and animations

## Tech Stack
- HTML
- CSS
- JavaScript
- JSON (data-driven content)

## How It Works
- User selects a province or territory from the dropdown
- JavaScript fetches data from a JSON file
- Page updates dynamically with images, text, fun facts, and video
- Local time updates in real-time based on the selected region

## How to Run
1. Clone or download the repository
2. Open `index.html` in any modern web browser  
   *(For best results, use a local server if your browser blocks `fetch` from local files)*
